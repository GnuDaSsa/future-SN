# ACT1 — 일상 속의 발견 (EP1~5 · 컷 1~36)

> 다섯 시민이 각자 성남시의 개선을 우연히 발견하는 옴니버스 묶음. 각 EP = 시책 1개 + 주인공(들).
> 공통 공식: **불편 빌드업 → 포기 직전 → (전환/매치컷) 개선 발견 → 체험 → 감탄**.

| EP | 폴더 | 주인공 | 시책 | 컷 |
|---|---|---|---|---|
| EP1 | [`ep1-escalator/`](ep1-escalator/) | 초등학생 | 도로 에스컬레이터(금광동 성남동초) | 1~7(repo 10컷) |
| EP2 | [`ep2-trashbin/`](ep2-trashbin/) | 시민 여성 | 가로 쓰레기통(여수동) | 8~14(repo 10컷) |
| EP3 | [`ep3-solomon/`](ep3-solomon/) | 청년 C3·C4 | 솔로몬의 선택(매칭) | 15~22 |
| EP4 | [`ep4-flu/`](ep4-flu/) | 환자 C5 | 무료 독감 예방접종 | 23~29 |
| EP5 | [`ep5-clay/`](ep5-clay/) | 노부부 C6·C7 | 율동공원 맨발 황톳길 | 30~36 |

> 이후 ACT2(`../act-02-tancheon/`)에서 이 다섯 사연의 주인공이 탄천으로 모이고, ACT3(`../act-03-droneshow/`)에서 드론쇼로 마무리된다.

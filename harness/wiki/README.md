## 🎬 영화 반영 액션 아이템
1. **에스컬레이터**: 상·하행 각 1줄로 묘사(과장 금지).
2. **쓰레기통**: 에셋 시트에 "색·투입구는 실제 사진 기준" 1줄 단서, 가짜 공식 사업명 자막 금지.
3. **솔로몬의 선택**: C3·C4 성남 거주/직장인 암시 한 컷, 통계 자막은 수치 빼고. 포스터 문구는 현행 OK.
4. **독감접종**: 장면 시점을 '독감 시즌(가을~봄)'으로, 각주 1줄(연령 제한 없음·순차).
5. **황톳길**: 숲그늘+빛샤프트 톤, 비동절기 전제(겨울이면 비닐터널이라 비주얼 상이).
6. **드론쇼**: ACT2는 탄천변 일대 운집감. ACT3 민선 문구는 '가공 연출'임을 인지(사실 기반이면 "희망 성남" 류 도시브랜딩 문구가 적합).
